# ご当地キャラの乱 〜日本列島縦断〜

日本全国の都道府県を巡り、地域データによって強さが変わるご当地キャラクターたちと戦う、ブラウザで遊べるRPGです。
ドット絵の日本列島を歩き、北海道・東北・関東・中部・近畿・中国四国・九州の7地方の城を北から順番に制覇していきます。本土を制覇すると、離島編（西表島 → 小笠原諸島 → 北方領土）の3つの城に挑めます。

## 遊び方

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| 移動 | 矢印キー / WASD | 十字キー |
| 決定・調べる | Z / Enter / Space | Aボタン |
| メニュー・戻る | X / Esc | Bボタン |

- 城にぶつかると話しかけられ、ボス戦に挑めます。次に攻略する城の旗は金色に点滅します。
- 草むらや山を歩くとランダムエンカウントが発生します（道と橋の上では発生しません）。
- 城を制覇すると、そのエリアのご当地キャラが仲間になります。メニューの「なかま」で2人まで連れていけます。
- 進行状況はブラウザの localStorage に自動保存されます。

## 主な機能：リアルデータ連動型の敵ステータス

各都道府県のデータを地方ごとに集計し（最高峰は最大値、森林率は平均、魅力度は所属県の順位の平均で全エリアを順位付け）、そのまま敵キャラクターの強さと属性に反映します。名物・キャラは城のある県（北海道・宮城・東京・愛知・大阪・広島・福岡）のものを使います。離島は島ごとのデータを持ち、魅力度順位は所属する都道府県の値を使います。計算式は `src/data/prefectures.js` の `mods()` にあります。

| 地域データ | 効果 |
| --- | --- |
| 最高峰の標高 | 防御力アップ（富士山の3,776mで ×1.5） |
| 森林率（地形の険しさ） | 素早さアップ |
| 名物のグルメ指数 | HP と必殺技の威力アップ |
| 魅力度ランキング | 上位のエリアほどレベルが上乗せされ「強敵」になる |

属性は「森林率50%未満 → 街 / 最高峰2,000m以上 → 山 / それ以外 → 海」で決まり、山は街に、街は海に、海は山に強い（1.5倍）三すくみです。

## データ図鑑とデータ攻撃（北海道・東北）

本物のオープンデータを「知っているほど有利になる」仕組みです。

1. **覚える**：各県の県庁所在地の近くの道ばたに看板が立っています（北海道・東北で17枚）。調べるとその県のデータが読め、メニューの「図鑑」に記録されます。まだ読んでいない看板はメニューの「地図」に水色で出ます。
   看板は3種類で、板の色が違います。

   | 看板 | 色 | 例 |
   | --- | --- | --- |
   | 食べもの | 木の色 | 山形は外食のラーメンに1年で21,695円使い、全国1位 |
   | おやつ・飲みもの | ピンク | 福島はアイスとプリンが全国1位 |
   | くらし | 水色 | 青森は灯油が全国1位、山形は水道代と給食費が全国1位 |

2. **試される**：ボスは2ターンに1回「データ攻撃」でクイズを出します。問題は5種類で、順番に出ます。

   | 種類 | 例 |
   | --- | --- |
   | 1位当て | 「納豆」にいちばんお金を使う県は？（福島 / 岩手 / 秋田 / 茨城） |
   | どっち | 「ほたて」にお金を使うのは、北海道と青森のどっち？ |
   | 順位当て | 岩手の「納豆」は、全国で何位？ |
   | 金額当て | 青森の1世帯が、1年に「りんご」に使うお金は？ |
   | 本当の1位 | 「秋田の乾めん」「宮城のわかめ」…本当に全国1位なのはどれ？ |

   正解すると攻撃を跳ね返して敵に最大HPの15%のダメージ、不正解だと味方全員が大ダメージを受けます。
   答えの後には正解の数字が表示されるので、外しても覚えられます。

データは総務省統計局「家計調査（二人以上の世帯）品目別都道府県庁所在市ランキング（2023年～2025年平均）」の
1世帯あたり年間支出金額です。県の値はその県の県庁所在市の値です（北海道は札幌市、東京は東京都区部）。
`scripts/build-kakei.py` が統計局の Excel から `src/data/kakei.js` を作ります。
どの県のどの看板に何の品目を書くかは `src/game/quiz.js` の `FACTS` で決めていて、ここに足せばほかのエリアにも広げられます。

## 技術スタック

- React 18（JSX）
- Vite 5
- HTML5 / CSS
- Canvas（フィールドのドット絵描画）
- Data Sources: 総務省「家計調査」（データ図鑑・データ攻撃）／地域データ（最高峰・森林率・名物・魅力度は参考値のサンプル）

## 開発

Node.js 18 以上が必要です。

```bash
npm install     # 初回のみ
npm run dev     # 開発サーバー（http://localhost:5173）
npm run build   # dist/ に本番用ファイルを出力
npm run preview # ビルド結果の確認
```

### 設計メモ

- **入力**：`useInput()` フックを使うと、画面が重なったとき一番上のコンポーネントだけがキー入力を受け取ります（会話中はフィールドが動かない、など）。
- **フィールド**：毎フレーム変わる主人公の位置は `useRef` に持ち、`requestAnimationFrame` で Canvas に描いています。React の再レンダリングは1マス進むごとの1回だけです。
- **戦闘**：行動の順番やメッセージ送りを `async/await` で書いています。StrictMode で effect が2回走っても、古い方の進行は止まるようにしています。

## データの差し替え

`src/data/prefectures.js` の `RAW` 配列が全県のデータです。1行が1県で、並びは次のとおりです。

```
[県名, 最高峰(m), 森林率(%), 名物, グルメ指数(0-100), 魅力度順位, キャラ名, 体色]
```

エリアの分け方と城を置く県は、同じファイルの `REGION_DEF` で決めています。

e-Stat（政府統計）や各自治体のオープンデータの値に置き換えると、そのままゲームバランスに反映されます。
グルメ指数は生産量・消費量などを 0〜100 に正規化した値を想定しています。

## 地図の作り直し

フィールドの日本地図（`src/data/japanMap.js`）は、都道府県の境界データ（[dataofjapan/land](https://github.com/dataofjapan/land) の `japan.geojson`）から作っています。1マスは約20kmです。

```bash
node scripts/build-map.mjs <japan.geojson のパス>
```

- 沖縄本島・八重山（西表島など）・小笠原は、実際の位置だと地図が広くなりすぎるので、拡大して枠つきの「はめ込み図」として置いています。北方領土は実際の位置のままです。
- 宮古島・大東諸島・奄美などの小さな島は省いています。佐渡島などの道のつながっていない島は、見えるだけで渡れません。
- 縮尺やはめ込み図の位置は `scripts/build-map.mjs` の先頭で変えられます。作り直したら `src/game/save.js` の `MAP_VERSION` を上げてください（古いセーブの位置をリセットするため）。

## GitHub Pages で公開する

1. このフォルダをリポジトリとして GitHub に push する
2. リポジトリの Settings → Pages で、Source を **GitHub Actions** にする
3. `main` に push するたびに自動でビルドされ、`https://<ユーザー名>.github.io/<リポジトリ名>/` に公開される

## 注意事項

- 地域データ（最高峰・森林率・名物・魅力度順位）は参考値のサンプルです。
- 登場キャラクターはすべてオリジナルで、実在のご当地キャラクターとは関係ありません。
